Plux Studio: third-party notices

This directory (/usr/share/doc/plux-studio) holds the notices of the software
the Studio image ships beyond Plux's own code (DEP-001). Plux Studio is
licensed AGPL-3.0-only. The legal review of this list is a condition of
release (P11 plan O-7) and is not closed by shipping it.

1. CanvasKit and Skia
   Studio draws the canvas with CanvasKit (canvaskit.js and canvaskit.wasm),
   the WebAssembly build of Skia that the Flutter engine ships, at the version
   pinned by studio/scripts/stage-canvaskit.ts (Flutter 3.47.5, each file
   checked against its SHA-256 before it enters the image). Skia is licensed
   under the BSD 3-Clause licence below. The build also contains further
   components that the Flutter engine lists in its own licence file (among
   them, for example, FreeType, HarfBuzz and ICU);
   their notices travel with the Flutter SDK of the same version, and the
   complete enumeration for this binary is part of the open review.

3. Fonts
   - The canvas draws device text with Roboto and Noto Sans: their SIL Open
     Font License 1.1 texts are in the fonts/ folder of this directory.
   - The interface fonts (Instrument Sans, Instrument Serif, Sora, DM Mono,
     Noto Sans Arabic, Noto Naskh Arabic) come from the @fontsource packages;
     their licence files, SIL Open Font License 1.1, are in the folders of
     those packages below.
   - SF Pro is not part of the image: Studio reads the copy installed on a
     Mac through the browser's Local Font Access.

4. Monaco, Phosphor and every other package
   The licence and notice files of each production dependency of the Studio
   workspace, among them monaco-editor (MIT), @phosphor-icons/core (MIT),
   React, CodeMirror, TanStack and Lingui, are copied unmodified into one
   folder per package, below this directory (scripts/release/js-notices.sh).
   The same list is the SBOM that the release attaches to the image.
