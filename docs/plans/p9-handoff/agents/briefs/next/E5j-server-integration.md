## Your task: P9 integration (Go) — close the seams the merged server slices left (`ABT-006`, `ABT-002`, `REL-053`, `ANL-011`, `SEC-142`, `SYN-060`)

1. **Experiment prop defaults in the bundle (ABT-002).** With no control document (or no entry for an experiment), `experiment.<key>.<prop>` bindings fail on the device and the page falls back. Have the compiler embed, per experiment the bundle uses, the control arm's value of each declared prop (from the experiment document, `schema/json/experiment.schema.json`) so the runtime can default to control — additive FlatBuffers field (`schema/fbs/bundle.fbs` or the experiments section the E5 contracts added; grep `Experiment` in `schema/fbs`), deterministic (CMP-002), conformance vectors and goldens updated with the repo's `-update` flags only where output legitimately changes. Then make the Dart runtime read the defaults (`packages/plux_flutter/lib/src/experiments/`), one test each side.
2. **Typed flag accessors (ABT-006):** `plux codegen` (grep `backend/cmd/plux/cmd_codegen*.go` and `backend/internal/codegen`) generates typed host accessors for the app document's flags (Dart), like the existing typed routes; golden test.
3. **Health-gate error rates (REL-053).** The rollout health gate (`backend/internal/rollout/signals.go`) expects rollup series `action_error` and `function_error`; the analytics rollups have no result/status dimension. Derive them in the analytics ingestion from the existing action and function events (grep the event names in `packages/plux_flutter/lib/src/telemetry/events.dart` and `backend/internal/telemetry`), additively, with a test that the gate sees them.
4. **Schedule the enterprise exports (ANL-011).** `ee/backend/analytics` has `ParquetExporter` and `WebhookExporter` but nothing schedules them, and the core object store does not satisfy their `ObjectStore.Put(ctx, key, io.Reader, contentType)`: add a periodic worker job through a public seam (the pattern of `backend/ext/export`), an adapter over `backend/internal/storage/objects`, and per-organisation export settings in the existing analytics export configuration.
5. **Generated control-document verifier layout (SYN-060).** `packages/plux_flutter/lib/src/control/control_reader.dart` carries a hand-written FlatBuffers verifier layout because the generator does not emit one for `schema/control.fbs`; make the existing layout generator (`grep -rn "layout.g.dart" mk tools backend`) cover `control.fbs` and use its output.
6. **Test:** release retention keeps a development release a reconstruction references (`ListPurgeableReleases` in `backend/internal/storage/queries/releases.sql` already excludes them; add `TestPurgeKeepsReconstructedReleases_SEC_142` in `backend/internal/release`).
