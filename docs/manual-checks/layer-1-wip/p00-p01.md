- **Do:**
  1. `gh api repos/{owner}/{repo}/rulesets`, then `gh api repos/{owner}/{repo}/rulesets/<id>`
     for the ruleset whose target is the default branch.
  2. On GitHub: **Settings → Rules → Rulesets**, open the same ruleset.
- **Expect:** rules `pull_request` (Code Owners review on), `required_status_checks` with
  **CI OK**, `required_linear_history`, `non_fast_forward` and `deletion`; squash merge only.
- **Why:** the ruleset lives in GitHub, not in the repository, so no test can see it (CI-009).
- **Look at:** [ci.md](../../engineering/ci.md) "Ruleset on `main`"; `.github/CODEOWNERS`.
- **Moves to DONE when:** this result is recorded and the Scorecard workflow's
  Branch-Protection result on `main` agrees.
