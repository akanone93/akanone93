- **Moves to DONE when:** the phone's numbers, model and OS are in `docs/benchmarks/p5-actions-data.md` and meet the budget.

### L1-RUN-505 — The local database is encrypted on a phone under `strict` (DB-002)

- **Needs:** R-STACK, R-TOKEN, R-L1-MID
- **Do:**
  1. `plux security config set --env development --profile strict --expected-version <n>`
     (`<n>` from `plux security config show --env development`).
  2. Run the Dev app in debug on the phone (`cd apps/plux_dev && flutter run -d <phone-id>` with
     the defines of `apps/plux_dev/README.md`); it is the one host app with `plux_db_drift`.
  3. In `schema/testdata/documents/db` run `plux dev`, pair the phone, open a collection page.
  4. Copy the `.db` file out with `adb exec-out run-as dev.plux.dev cat <path>` and open it with `sqlite3`.
- **Expect:** the page shows its rows; `sqlite3` says "file is not a database".
- **Why:** under `strict` and `maximum`, Drift runs on SQLCipher with a hardware-wrapped key (DB-002, SEC-073).
- **Look at:** an adapter without encryption is refused with `DB_ENCRYPTION_REQUIRED` (`docs/reference/errors.md`).
- **Moves to DONE when:** this passes on the phone; the host tests `[DB-002]` in
  `packages/plux_db_drift/test/drift_adapter_test.dart` cover the rest.
- **Result:** ☐ pass ☐ fail — notes:
