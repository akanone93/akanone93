# Plux Studio Guides

Short, task-oriented guides to Plux Studio, the web application where you design apps, plugins,
pages and actions, publish them and watch them run. Each guide covers one area of Studio's
navigation and names the screens and buttons as the interface labels them. To run Studio on your
machine first, follow [Run it locally](../run-locally.md) §4.

| Guide | Use it to |
|---|---|
| [Apps](apps.md) | Find your apps in the grid or list, read a card, pin, duplicate, export and archive an app, and read its limits usage |
| [Canvas and editing](canvas.md) | Arrange plugins on the app canvas, edit screens on the plugin canvas, link screens, undo, recover from conflicts and restore snapshots |
| [Publishing and releases](publishing.md) | Publish plugins, read the build reports, roll out, pause, roll back and switch a plugin off |
| [Functions](functions.md) | Inspect deployed functions, see their capabilities and metrics, and edit Rust source |
| [Data](data.md) | Import API definitions, edit mocks, and design on-device collections and migrations |
| [Localisation](localisation.md) | Review translation keys by locale, approve in bulk, import and export |
| [Design system](design-system.md) | Edit tokens, themes, brand overlays and fonts, and reuse components and templates |
| [Analytics and replay](analytics.md) | Read usage, funnels, errors and performance, and replay a session |
| [Experiments and flags](experiments.md) | Create an experiment from the canvas, read results, and ship a winner or flip a flag |
| [Plux Test](plux-test.md) | Write test scenarios and read the runs that `plux test` and CI report |
| [Administration and security](security-and-admin.md) | Pair devices, manage approvals, members, roles and sign-in, and read the audit log |

Keyboard: `Mod+K` opens the command palette, `Shift+?` lists every shortcut, `Mod+Z` and
`Mod+Shift+Z` undo and redo, `Alt+H` goes home, `Alt+P` opens your profile and `Alt+T` switches the
theme. Studio runs in English, German and Arabic (right-to-left); choose the language in your
profile. The [engineering view](../../engineering/studio-development.md) of the same application is
for contributors.
