# Changelog

## 0.1.0

The first release: `FunctionEngine`, which runs device-placed Plux Functions in WAMR's interpreter on a worker isolate, with time, memory, output and log limits, cancellation, and the `plux_v1` host calls served by a `DeviceFunctionHost`.
